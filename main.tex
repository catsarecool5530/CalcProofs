\section{Sample Proof}

This document demonstrates the basic LaTeX setup for writing calculus proofs.

\begin{theorem}[Derivative of a Constant]
If $c$ is a constant, then $\dd{x}c = 0$.
\end{theorem}

\begin{proof}
By the definition of derivative:
\begin{align}
\dd{x}c &= \lim_{h \to 0} \frac{c - c}{h} \\
&= \lim_{h \to 0} \frac{0}{h} \\
&= \lim_{h \to 0} 0 \\
&= 0
\end{align}
\end{proof}

\begin{example}
Consider the function $f(x) = 5$. Then $f'(x) = 0$ for all $x \in \R$.
\end{example}
